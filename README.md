## Практична робота №1: застосунок «Про застосунок»

Застосунок «Про застосунок» для вигаданої платформи Releaf — віртуального лісу, де користувач садить цифрове дерево, а партнери компанії садять справжнє.

### Що всередині

| Файл | Призначення |
| --- | --- |
| `index.html` | розмітка: заставка і головний екран |
| `style.css` | стилі та анімація переходу |
| `logo.svg` | основний логотип (векторний, для світлої теми) |
| `logo-dark.svg` | той самий логотип для темної теми |

### Як запустити

Збирати нічого не треба. Відкрийте файл `index.html` у браузері (подвійний клік або «Відкрити за допомогою» → Chrome / Edge / Firefox).

1. Спершу з'являється заставка з логотипом і смужкою завантаження.
2. Через 2,5 секунди вона плавно зникає, і видно головний екран «Про застосунок».

Перехід зроблено через CSS-анімацію (`@keyframes hide` у `style.css`), без JavaScript.

Після заставки в правому верхньому куті є кнопка «Тема» — вона перемикає світлу й темну тему (також без JavaScript: прихований чекбокс + CSS-змінні). У темній темі використовується окремий варіант логотипу `logo-dark.svg`.
